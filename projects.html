SmartAttend AI — Face Recognition Attendance System

A web-based attendance management system that uses face recognition to identify registered students and automatically record their attendance.

Live demo Source on GitHub
ProblemWhy it exists

The problem

Manual attendance can take time and requires maintaining student records separately. SmartAttend AI was developed to simplify attendance by using face recognition to identify registered students and record attendance automatically.

ArchitectureStack decisions

System architecture & stack choice

The application combines a web-based frontend with a Python Flask backend, computer-vision functionality, face recognition, and SQLite database storage.

  • HTML, CSS and JavaScript for the frontend
  • Python and Flask for backend development
  • OpenCV for camera and image processing
  • Face Recognition for student identification
  • SQLite for student and attendance records
FeaturesWhat shipped

Key features

  • Student registration with name, roll number, and photo
  • Live face recognition using the camera
  • Automatic attendance marking
  • Attendance records and tracking
  • Update and delete student details
  • Web-based attendance dashboard
  • Fast real-time recognition and response
WorkflowHow it works

Application workflow

Students are first registered with their basic information and photograph. During attendance, the camera captures the student's face and the recognition system compares it with registered data. Once the student is identified, attendance is recorded and made available through the dashboard.

LearningDevelopment experience

What I learned

This project gave me practical experience with Python, Flask, computer vision, face recognition, camera input, database operations, and integrating AI/ML functionality into a web application.
